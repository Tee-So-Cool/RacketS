# เทียบไม้แบด (ใช้เอง)

เว็บเทียบไม้แบด / เทียบเอ็น / จับคู่ไม้+เอ็น แบบไฟล์ static ไม่ต้อง build

## เปิดใช้

```bash
cd /Users/tee/MyPro/RacketS && python3 -m http.server 8765
```

แล้วเปิด http://localhost:8765

## เพิ่ม/แก้ข้อมูล

- **ทางเว็บ:** แท็บ "จัดการข้อมูล" → เพิ่ม / แก้ไข / ทำสำเนา / ลบ (เก็บใน localStorage ของเบราว์เซอร์)
  แล้วกด **Export** เอาไฟล์ที่ได้มาทับ `data/rackets.js` หรือ `data/strings.js` เพื่อเก็บถาวร
- **แก้ไฟล์ตรง ๆ:** `data/rackets.js`, `data/strings.js` (ถ้าเคยแก้ทางเว็บไว้ ต้องกด "รีเซ็ต" ก่อน เว็บถึงจะอ่านจากไฟล์)

ทริก: ไม้รุ่นใหม่ที่สเปกคล้ายรุ่นเดิม ใช้ปุ่ม "ทำสำเนา" แล้วแก้แค่ชื่อ/ปี/ราคา

## หมายเหตุ

- สเปกตั้งต้นกรอกจากข้อมูลทั่วไป ราคาเป็นราคาประมาณ ควรเช็กกับเว็บผู้ผลิต/ร้านอีกที
- กราฟบุคลิกไม้ และคะแนนจับคู่ คำนวณจากสเปก (สูตรอยู่ใน `app.js` ฟังก์ชัน `racketProfile` และ `score`)
